# Contributing

## Issues are welcome

Report a bug or ask for a feature with the forms of *New issue*. Questions go to
[Discussions](https://github.com/Novior-dev/MentorAgent/discussions), and a vulnerability goes privately to the
address in [SECURITY.md](SECURITY.md). [SUPPORT.md](SUPPORT.md) says where each thing goes.

## Pull requests: not for now

This repository is a copy of our internal one, published at every release, so a change merged here would be lost
with the next release. If you have a fix in mind, describe it in an issue: we make the change in the internal
repository, and it comes here with the release.

## What happens to an issue

When we confirm a bug or accept a request, it becomes an item of our internal backlog, with a link to the issue.
The backlog is where the work is planned and followed; the issue stays the place to talk about it with you. The
change ships in a release, and [CHANGELOG.md](CHANGELOG.md) says what each release changed.
