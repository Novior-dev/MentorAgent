# Support

| You have | Where it goes |
|---|---|
| A question on how to use MentorAgent | [Discussions](https://github.com/Novior-dev/MentorAgent/discussions), in the Q&A category |
| A bug: something does not work as the README says | A new issue, with the *Bug report* form |
| A feature you need | A new issue, with the *Feature request* form |
| A vulnerability | Never a public issue: write privately to **security@mentoragent.net**, as [SECURITY.md](SECURITY.md) says |

Search the issues and the discussions first: the answer may be there already.

We answer questions and issues as best we can, with no guaranteed response time. A vulnerability report is
acknowledged within 5 working days, best effort. Which versions still get fixes, and for how long, is in
[SECURITY.md](SECURITY.md#supported-versions).

[CONTRIBUTING.md](CONTRIBUTING.md) says what happens to an issue once we confirm it, and why we do not take pull
requests for now.
